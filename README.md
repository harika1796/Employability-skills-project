# Gym Management System

A console-based Gym Membership Management System
developed using Java.

## Features

- Member Registration
- Membership Plan Selection
- Membership Renewal
- Attendance Management
- Trainer Management
- Trainer Allocation
- Input Validation
- Custom Exception Handling

## Technologies Used

- Java
- OOP Concepts
- ArrayList
- Java Exception Handling
- Java Date and Time API

## Project Structure

The project follows a modular package-based
architecture with separate model, service,
exception, utility and application packages.

## How to Run

Compile and run the Java application.
