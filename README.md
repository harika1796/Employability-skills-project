

\# Gym Membership Management System



\## Project Overview

A console-based Java application designed to manage gym memberships, attendance, and trainer allocation.



\## Features

\- Register new gym members

\- View registered members

\- Display available membership plans

\- Select and renew membership plans

\- Mark and view attendance

\- Register trainers

\- Assign trainers to members

\- Handle invalid inputs using custom exceptions



\## Technologies Used

\- Java

\- Object-Oriented Programming

\- ArrayList

\- Exception Handling



\## How to Run



1\. Open Command Prompt.

2\. Navigate to the project folder.

3\. Compile the program:



&#x20;  javac GymManagementSystem.java



4\. Run the program:



&#x20;  java GymManagementSystem



\## Project Type

Core Java Console Application
